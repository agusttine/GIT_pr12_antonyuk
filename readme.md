> [!NOTE]
> Так же хочу упомянуть, что Вам придется пройти проверку на человека перед началом использования.

```python
while True:
    print("Вы человек? 1- да, 2-нет")
    try:
        proverka = int(input())
    except ValueError:
        print("Нет такого варианта выбора! давайте ещё раз!")
        continue

    if proverka not in (1, 2):
        print("Нет такого варианта выбора! давайте ещё раз!")
        continue
    break
```
