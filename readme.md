## Описание программы

Программа _проверяет_, что перед использованием ПО пользователь прошёл
проверку на человека, и не пускает дальше, пока не получит __честный ответ__.

### Необходимые условия

Что нужно для установки программного обеспечения и как его установить:
 1. компьютер
 1. Git
 1. Python 3.10+

> [!NOTE]
> Так же хочу упомянуть, что Вам придется пройти проверку на человека перед началом использования.

```python
while True:
    print("Вы человек? 1- да, 2-нет")
    try:
        proverka = int(input())
    except ValueError:
        print("Нет такого варианта выбора! давайте ещё раз!")
        continue

    if proverka not in (1, 2):
        print("Нет такого варианта выбора! давайте ещё раз!")
        continue
    break
```
> [!WARNING]
> Программа не проверяет, правда ли вы человек — она верит вам на слово.
> Используйте ответственно.
